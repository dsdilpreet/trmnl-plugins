# TRMNL Plugins
Plugins for [TRMNL](https://trmnl.com) E-INK Display. 

## Plugins
Each directory contains a plugin.
 
### Google Health (Fitbit)
Displays your daily activity and recovery metrics from Google Health.

### YouTube Charts
Displays daily and trending music videos from YouTube Music, with support for global or country-specific chart views.
